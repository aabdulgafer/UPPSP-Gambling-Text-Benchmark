# UPPS-P Gambling Text Benchmark

Research artifacts supporting the benchmark of pretrained language encoders for five UPPS-P impulsivity facets in synthetic gambling-related text.

## Contents

- `src/`: original training, evaluation, and statistical analysis scripts
- `configs/`: split manifests and an example encoder configuration
- `results/`: metrics, statistical comparisons, baseline prediction files, and original result archives
- `figures/`: figures accompanying the manuscript
- `docs/RELEASE_STATUS.md`: availability and reproducibility status
