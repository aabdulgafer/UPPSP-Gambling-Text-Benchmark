# Release status

This repository contains original experiment artifacts and selected result archives. Dataset files are hosted separately and must be linked in the README.

The baseline prediction export includes an audit record marked PASS; its runner SHA-256 matches the included `src/training/run_classical_baselines.py`. This is not a claim that all model runs have been independently reproduced.

The NeoBERT seed-87 configuration and training history are examples from one run, not complete histories for all 27 runs. Large model checkpoints are not included. Exact dataset release, dependency environment, licenses, and executable reproduction instructions should be verified before public release.
